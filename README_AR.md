# واجهة مركز المأمون الطبي التشخيصي

هذه الحزمة تتضمن واجهة رئيسية احترافية ثابتة (Static Frontend) جاهزة للرفع إلى GitHub Pages.

## الملفات
- `index.html`
- `assets/style.css`
- `assets/script.js`

## طريقة الرفع
1. افتح مستودع GitHub الخاص بالموقع.
2. ارفع ملف `index.html` إلى الجذر.
3. ارفع مجلد `assets` كاملًا كما هو.
4. إذا كان الموقع يعمل عبر GitHub Pages فسيتم تحديث الواجهة بعد دقائق.
