# المرحلة الثانية — مركز المأمون

## ما تم تنفيذه
- قائمة هاتف قابلة للفتح والإغلاق.
- صفحة بحث محلي في محتوى صفحات الموقع (search.html).
- تحسين تهيئة الصفحات للأجهزة المحمولة وإضافة وصف ووسم robots.
- صفحة 404 وروابط بحث سريعة.

## التحديث على GitHub
ارفع كل الملفات والمجلدات الموجودة في هذه الحزمة إلى **جذر المستودع نفسه** مع استبدال الملفات القديمة، ثم راقب Actions حتى تظهر علامة نجاح خضراء.

## مطلوب قبل إطلاق الخدمات التفاعلية
- إعداد Supabase URL وanon key وصلاحيات RLS المناسبة، بعد فحص مخطط قاعدة البيانات الفعلي.
- إعداد رقم الاتصال والعنوان الرسمي والصور المعتمدة.
- اختبار إرسال الحجوزات والصلاحيات قبل الإعلان عن تفعيلها.
- لتوليد sitemap.xml دقيق، يلزم رابط الموقع المنشور.

هذه المرحلة لا تتضمن لوحة تحرير فعلية أو حفظ حجوزات في قاعدة البيانات.
