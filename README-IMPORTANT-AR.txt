إصلاح موقع المأمون — نسخة مستقلة عن مجلد assets

سبب الإصلاح: ظهور الصفحة بدون ألوان وخطوط، مع صورة شعار مكسورة، يشير إلى عدم تحميل ملفات assets.

1. فك الضغط عن ZIP.
2. افتح مستودع GitHub: almamoondmcenter-glitch/almamooncenter
3. من المستودع: Add file → Upload files.
4. ارفع جميع ملفات HTML التي في المستوى الأول، ويجب أن تظهر index.html و admin.html مباشرة في جذر المستودع.
   لا ترفع المجلد الحاوي لها ولا ZIP، بل الملفات داخله.
5. اضغط Commit changes، وانتظر Pages/Actions.
6. افتح https://almamoondmcenter-glitch.github.io/almamooncenter/admin.html
7. إذا رأيت نسخة قديمة حدّث الصفحة بالقوة أو افتح نافذة خاصة.

مهم: لا تنفذ SQL من جديد إذا سبق تشغيله، ولا تحذف قاعدة البيانات أو بيانات الحجوزات.
تحتوي صفحات HTML هذه على CSS وجافاسكربت الأساسية مباشرة بداخلها؛ لذلك لا تحتاج إلى رفع مجلد assets لإصلاح العرض.
مكتبة supabase-js تستدعى من cdn.jsdelivr.net؛ إذا حُظر هذا الموقع ستظهر رسالة واضحة بالخطأ.
الشعار مضمن داخل الصفحات أيضًا لتجنب ظهور الصورة المكسورة.

النسخة لا تعني أن الربط تم اختباره على الخادم الحي أو أن جميع وظائف Supabase تعمل.
