موقع مركز المأمون الطبي التشخيصي - نسخة جاهزة للرفع إلى GitHub Pages
================================================================

النسخة المرفقة تصلح مشكلة اختفاء التنسيقات في حال رفع index.html وحده:
كل CSS وJavaScript والرسومات التوضيحية مضمّنة داخل ملف index.html.
لا يلزم إنشاء مجلد assets أو رفع ملفات إضافية لعرض التصميم.

طريقة النشر:
1) ادخل إلى مستودع الموقع على GitHub.
2) ارفع ملف index.html إلى مجلد النشر المعتمد (عادةً جذر المستودع).
3) إذا كان هناك index.html سابق، استبدله بعد أخذ نسخة احتياطية.
4) من Settings -> Pages اختر Deploy from a branch ثم main و/(root) إذا كان مناسبًا للمستودع.
5) بعد اكتمال النشر حدّث الصفحة وأفرغ ذاكرة التخزين المؤقت عند الحاجة.

تنبيه: النموذج واجهة أمامية فقط، ولا يوفّر لوحة إدارة أو نظام حجوزات خلفي.
الرسومات توضيحية والشعار مؤقت، وتحتاج البيانات الفعلية (الفيديو، الشعار، العيادات) إلى اعتماد قبل الإطلاق.
