# مركز المأمون الطبي التشخيصي — الموقع ولوحة الإدارة

## ما الذي تم تنفيذه؟
- واجهة عربية RTL، سلايدر، صور فوتوغرافية توضيحية، خدمات، أطباء، أخبار، باقات، معرض، التحضيرات، أوقات الدوام، الشركاء، خريطة وروابط تواصل.
- لوحة إدارة `admin.html` تشمل ملخص المحتوى، إضافة/تعديل/حذف/نشر/إخفاء العناصر، بيانات المركز، متابعة الحجوزات ورسائل التواصل.
- وضع تجريبي محلي يعمل بدون خادم؛ **لا ينشر التعديلات ولا يحفظ حجوزات الزوار**.
- تكامل Supabase اختياري: مصادقة الموظفين، قاعدة بيانات مع RLS، وإدارة المحتوى والحجوزات.

## النشر على GitHub Pages
1. ارفع **جميع** ملفات الحزمة بنفس المجلدات، بما فيها `assets` و`.nojekyll`، إلى جذر المستودع.
2. Settings → Pages → Deploy from branch → main / root.
3. الصفحة العامة: `https://USERNAME.github.io/REPOSITORY/`، لوحة التحكم: `https://USERNAME.github.io/REPOSITORY/admin.html`.
4. اختبر الموقع والجوال، وتحقق من ظهور CSS والصور. الصور الخارجية تتطلب الإنترنت وقد تتغير؛ الأفضل استبدالها بصور المركز المرخّصة.

## تفعيل قاعدة البيانات والحماية
1. أنشئ مشروعًا خاصًا في Supabase، وافتح SQL Editor وشغّل `database/schema.sql`.
2. افتح Authentication → Users وأنشئ مستخدم الإدارة بالبريد وكلمة مرور قوية مع تفعيل MFA إذا توفر.
3. انسخ UUID للمستخدم إلى أمر `insert into public.staff_profiles` المشروح في آخر ملف SQL وشغله من SQL Editor.
4. ضع **Project URL** و**publishable/anon key فقط** في `assets/js/config.js`. لا تضع أبدًا service_role أو كلمة مرور في الموقع.
5. افتح `admin.html` وسجل دخولك. اختبر إنشاء خدمة وتعديلها ثم افتح الصفحة العامة.
6. أنشئ أول محتوى عبر لوحة الإدارة: عند الاتصال بـ Supabase، قوائم المحتوى تبدأ فارغة إلى أن تدخل العناصر. البيانات التجريبية في `data.js` تظهر فقط قبل الاتصال.
7. أعد تفعيل سياسات الأمان والتحقق من صلاحيات الحسابات قبل استقبال طلبات حقيقية. امنع التسجيل المفتوح إذا لم تكن تحتاجه.

## تنبيهات التشغيل
- GitHub Pages يستضيف ملفات ثابتة فقط؛ لا يوفر قاعدة بيانات أو خادمًا لحفظ الحجوزات.
- طلبات الحجز المرسلة بعد الاتصال بقاعدة البيانات هي **طلبات وليست مواعيد مؤكدة**.
- لا تضع نتائج تحاليل أو صور مرضى أو معلومات طبية حساسة في CMS أو مستودع GitHub. بوابة نتائج المرضى تحتاج نظامًا خاصًا مع تحقق هوية وصلاحيات وصول وتدقيق أمني.
- لم تُفعّل بوابة الدفع الإلكتروني أو الربط البنكي أو البريد أو SMS أو إرسال إشعارات آلية؛ يلزم مزودون وخدمات خلفية.
- لا يوجد رفع ملفات مباشر من لوحة الإدارة؛ أدخل رابط الصورة المعتمدة، أو ارفعها إلى مستودع `assets/img` أو مساحة تخزين موثوقة.
- حماية نماذج الحجوزات العامة من الرسائل الآلية تحتاج CAPTCHA وتحديد معدل الطلبات في طبقة خادم قبل الإطلاق الفعلي.
- سياسات الخصوصية والموافقة والاحتفاظ بالبيانات يجب اعتمادها من إدارة المركز.
