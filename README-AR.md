# مركز المأمون الطبي التشخيصي — النسخة المحسنة

## طريقة النشر
1. افتح مستودع GitHub الخاص بموقع المركز `almamooncenter`.
2. استبدل ملف `index.html` في جذر المستودع بالملف الجديد.
3. انتظر تشغيل GitHub Pages ثم قم بتحديث الصفحة مع مسح ذاكرة التخزين المؤقت إن لزم.

## التحديثات
- الهوية: أبيض وأخضر (#FFFFFF، #B5E97D، #477537).
- صور طبية واقعية توضيحية من Unsplash، مستضافة على نطاق images.unsplash.com، ويتطلب ظهورها اتصالًا بالإنترنت.
- احتفظنا بالرسومات السابقة كبديل عند فشل اتصال الصور الرئيسية.
- دليل خدمات مصور مكون من ثماني بطاقات وتصفية الأقسام.
- تحسين قسم خطوات المراجع والحجز والاستعلام عن النتائج.
- ترتيب أوضح للبطاقات والعناوين على الجوال.

## مهم قبل الإطلاق النهائي
- الصور الخارجية توضيحية وليست صورًا موثقة لأجهزة المركز أو لطاقمه الطبي. يُفضل استبدالها بصور المركز الرسمية بعد الحصول على الإذن.
- مواعيد العيادات وتوفر الفحوصات والأسعار وأرقام الإحصائيات تتطلب اعتماد الإدارة.
- زر الحجز الحالي يجهز رسالة واتساب ولا ينشئ موعدًا في قاعدة بيانات.
- استلام النتائج لا يفتح بيانات طبية شخصية حتى يتم ربطه بمنصة رسمية مؤمنة.
- مفتاح الخريطة أو رابطها والخدمات الخارجية تعتمد على اتصال الإنترنت.
- لتحويل الموقع إلى حل إداري متكامل تحتاج إلى خلفية/قاعدة بيانات ولوحة إدارة لاحقًا.

## المرجع
الواجهة محسنة انطلاقًا من نسخة HTML المحلية المرتبطة بالموقع الرسمي المنشور على GitHub Pages.
