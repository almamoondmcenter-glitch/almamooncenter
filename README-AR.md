# الواجهة الجديدة لمركز المأمون

هذه حزمة لإعادة تصميم الصفحة الرئيسية فقط دون تعديل نظام الحجز أو لوحة التحكم أو بقية صفحات المشروع.

## خطوات الرفع
1. افتح مستودع almamoondmcenter-glitch/almamooncenter على GitHub.
2. احفظ نسخة من index.html الأصلي (انسخه إلى index-old.html إذا أردت).
3. ارفع index.html وredesign.css وredesign.js إلى جذر المستودع (نفس مكان booking.html).
4. وافق على استبدال index.html الموجود فقط.
5. انتظر نشر GitHub Pages وحدّث المتصفح تحديثًا كاملًا.

## ملاحظات
- ملفات logo-original.jpg وfavicon.svg والصفحات الداخلية موجودة مسبقًا في المستودع، ولم نُعد تضمينها أو تعديلها.
- الصور المستخدمة في الواجهة روابط صور توضيحية خارجية؛ استبدلها بصور مرخصة فعلية من المركز بعد الموافقة.
- جميع روابط الحجز والخدمات توجه للصفحات الحالية ولا تدعي أن النظام الخلفي يعمل.
- لا توجد بيانات مرضى أو مفاتيح سرية ضمن الحزمة.
- التصميم الجديد لا يصلح تلقائيًا لوحة التحكم أو الحجز أو قاعدة البيانات؛ فهو واجهة بديلة فقط.
