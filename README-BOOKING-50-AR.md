# تحديث مركز المأمون — دليل التركيب النهائي

## أهم الإضافات

- ملف `booking.html`: نموذج حجز يتضمن جميع **33 خدمة**، مع اختيار اليوم خلال 90 يومًا، و24 ساعة للاختيار حسب رغبة الزائر. **لا تعني الساعات المعروضة توفر موعد مؤكد.**
- ملف `services.html`: تصفح وبحث وتصفية جميع الخدمات.
- ملف `service.html?id=mri`: صفحة تفاصيل لكل خدمة مع رسم طبي توضيحي وتعليمات التحضير.
- قسم الخريطة: بحث Google Maps عن اسم المركز والعنوان في جولة تعز؛ **دبوس الموقع غير مؤكد**، ويمكن تعديله عند تزويدنا برابط موقع المركز الدقيق.
- جدول 24 ساعة: المختبرات والأشعة بحسب بيانات المركز. العيادات والاستشارات وفق مواعيد متغيرة.
- لوحة `admin.html`: جدول الحجوزات الخاص بالمخولين مع تصفية وبحث وتحديث حالة وتصدير CSV.
- الدفع: أيقونات تشير إلى **الاستفسار** عن النقدي والكريمي وون كاش وجوالي وفلوسك، دون ادعاء توفرها أو تفعيل الدفع الإلكتروني.
- الواجهة: أخضر تفاحي `#A4CE3A` وحركات تفاعل وبطاقات ورسوم خدمات متجاوبة.

## الرفع على GitHub Pages

1. خذ نسخة احتياطية من المستودع الحالي.
2. فك ضغط الحزمة وارفع **محتوياتها** إلى جذر مستودع `almamooncenter`، خصوصًا مجلدَي `assets` و`media`.
3. اضغط Commit changes وانتظر نجاح Actions.
4. اختبر `index.html` و`booking.html` و`services.html` و`service.html?id=mri` و`admin.html`.

## Supabase والأمان

يستخدم الحجز جدول `public.booking_requests` الموجود أصلًا، بالحقول `name`, `phone`, `department`, `message`. يضع تفاصيل الموعد والخدمة في حقل `message` حتى **لا تحتاج إلى تشغيل SQL جديد أو تعطيل RLS**.

تظهر بيانات الحجوزات للمدير فقط بعد فحص `is_site_admin()`، ويعتمد أمن البيانات على سياسات RLS الأصلية؛ **تحقق منها قبل استقبال بيانات العملاء الحقيقية**.

لا تستخدم `service_role` أو Secret API Key في المتصفح. المفتاح `sb_publishable_...` عام.

الصفحة الجديدة تطلب فقط الاسم ورقم الهاتف ومعلومة الموعد؛ لا تضف بيانات صحية أو تقارير طبية إليها. لم يتم اختبار إرسال حجز فعلي على Supabase من هذه البيئة.

## ملاحظات ضرورية

- الرسومات المرفقة **توضيحية** وليست تصويرًا لأجهزة المركز. يمكن استبدالها بصورك المعتمدة ضمن `media/services`.
- خيارات الدفع أسماء **للاستفسار فقط** وليست شعارات رسمية أو بوابة دفع.
- لضبط الخريطة بدقة أرسل رابط مشاركة الموقع من Google Maps.
- بعض خدمات العيادات تحتاج تأكيد الجدول الفعلي قبل نشر أوقات محددة.
- يجب إجراء اختبارات الصلاحيات والحجز بعد النشر، فقد تختلف إعدادات Supabase في المشروع الفعلي.
