# مركز المأمون الطبي التشخيصي

واجهة موقع عربية متجاوبة مبنية باستخدام Next.js وTypeScript. **هذه نسخة أولية قابلة للتشغيل وليست نظامًا طبيًا إنتاجيًا مكتملًا.**

## التشغيل

```bash
npm install
npm run dev
```

افتح http://localhost:3000

## النشر

ارفع الملفات إلى مستودع GitHub ثم اربط المستودع بمنصة استضافة تدعم Next.js. استخدم `npm run build` للتحقق من البناء.

## ملاحظات مهمة قبل الإنتاج

- نموذج الحجز حاليًا للعرض فقط ولا يرسل أو يحفظ بيانات المرضى.
- يجب تنفيذ Backend وقاعدة بيانات وصلاحيات وإدارة حجوزات حقيقية قبل استقبال طلبات المرضى.
- بوابة النتائج والدفع والتكاملات الطبية ولوحة الإدارة غير منفذة بعد.
- يجب إضافة الشعار الأصلي والعنوان وأرقام الهواتف والصور المرخصة بعد اعتمادها.
- زر تبديل اللغة تجريبي، والترجمة الإنجليزية الكاملة غير منفذة.
- لا تضع بيانات مرضى حقيقية أو أسرار تشغيل في GitHub.

## نطاق التوسعة

PostgreSQL وAPI آمن ولوحة إدارة RBAC ونظام حجوزات فعلي وتكاملات LIS/RIS/PACS والمدفوعات والإشعارات بعد التعاقد مع مقدمي الخدمات.
