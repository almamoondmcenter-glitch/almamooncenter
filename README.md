# موقع مركز المأمون الطبي التشخيصي

موقع عربي ثابت مناسب لـ GitHub Pages.

## النشر
1. ارفع محتويات المجلد إلى جذر مستودع GitHub.
2. افتح Settings → Pages.
3. اختر Deploy from a branch ثم main و /(root) ثم Save.
4. افتح الرابط الذي يعرضه GitHub بعد اكتمال النشر.

## ملاحظات
- لا توجد لوحة إدارة أو إرسال حجوزات فعلي في النسخة الثابتة.
- يلزم إدخال بيانات الاتصال والعنوان المعتمدة، وصور الفعاليات والمحتوى الإعلامي.
- تفعيل لوحة الإدارة والحجوزات يحتاج Supabase وإعداد RLS واختبارات صلاحيات.
- يُرجى التحقق من شهادات الجودة والجوائز قبل عرضها كحقائق موثقة.
